# 창원경일고 11월 행사 통합 신청 페이지

현수막 통합 QR이 연결되는 휴대폰용 안내 페이지입니다.
주소: https://mathlhk15-glitch.github.io/gyeongil-2027-events/

## 올리는 방법
1. GitHub에서 저장소 이름을 정확히 `gyeongil-2027-events`로 새로 만들기 (Public)
2. index.html, logo.png, og.png, README.md 업로드
3. Settings → Pages → Branch: main / (root) → Save
4. 1~2분 뒤 위 주소가 열리는지 확인 → 그다음 현수막 QR 인쇄

## 고칠 곳
- 행사 정보·신청 주소: index.html 안의 `EVENTS` 한곳만 고치면 됩니다.
- 행사가 끝나면 자동으로 '행사 종료' 표시 후 아래로 내려갑니다.
- 미리보기: 주소 끝에 `?now=2026-11-18T09:00` 을 붙이면 그 시각 기준 화면을 볼 수 있습니다.
